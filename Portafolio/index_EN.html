SIA Web System (Academic Integral System)

This is a web system I created for a High School, where administrative staff and teachers can review students' background history, as well as their records, justifications and messages, in order to have better academic control of students.

The system has a role-based login, secure password system and security tokens. Within the system there is a Student Search where you can search by enrollment (ID), names, surnames or groups. When you have the selected student, you can break down their academic history such as their background, justifications and messages, where you can add, edit or delete. It also has a Database Administrator system for Administrative roles, they can modify and has a Search with Filter to have more specific results.

The system is developed with React, Node.js, Express and PostgreSQL.
